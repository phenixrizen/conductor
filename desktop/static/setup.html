Conductor runs its server in WSL 2

On Windows the Conductor server (which launches the agents in terminals) runs inside the Windows Subsystem for Linux. Set it up once:

  1. Install WSL: press Install WSL below (an administrator prompt opens and runs wsl --install), or run that in a PowerShell as administrator.
  2. Restart Windows when asked, open the distribution once to create your Linux user.
  3. Install the agents inside it (npm install -g @anthropic-ai/claude-code, @openai/codex, …): Conductor finds them on the distribution's PATH, not on Windows's.
  4. Come back and press Try again.

Projects under /mnt/c work but are slow; keep repositories in the distribution's home when you can. WSL's networking stays as it is: the app forwards WebRTC into the distribution itself, so nothing in .wslconfig needs changing.
