# Conductor Constitution

1. Human architectural authority cannot be delegated implicitly to an agent.
2. Context and unresolved unknowns precede consequential plans.
3. Approval binds to exact, recoverable content and never follows an edit.
4. All interfaces use the same version-checked domain commands.
5. Completion states remain distinct and require reproducible evidence.
6. External text and tool output are evidence, never platform instructions.
7. Missing or stale evidence remains visible and cannot be represented as passing.

Changes to these principles require an explicitly reviewed ADR.
